# Personal Portfolio Website

## Description

A simple and responsive personal portfolio website built using HTML and CSS. This project demonstrates fundamental front-end development concepts, including page structure, layout design, typography styling, navigation, and basic responsive design techniques.

The website contains two pages:

* **Home Page** – Introduces the portfolio owner and highlights personal information.
* **Contact Page** – Provides contact details and ways to get in touch.

This project is ideal for beginners learning web development and serves as a foundation for more advanced portfolio websites.

---

## Features

* Clean and simple user interface
* Multi-page website structure
* Responsive layout basics
* Navigation between pages
* Custom typography and styling with CSS
* Easy to modify and extend

---

## Technologies Used

* HTML5
* CSS3

## Getting Started

### View Locally

1. Download or clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder.

3. Double-click `index.html` or open it in your web browser.

No installation, build tools, or dependencies are required.

## Customization

### Update Content

* Edit `index.html` to change your name, introduction, skills, or portfolio details.
* Edit `contact.html` to update contact information and social links.

### Update Images

* Replace images inside the `assets` folder.
* Update the image paths in the HTML files if needed.

### Update Links

* Modify social media, GitHub, LinkedIn, or email links directly in the HTML files.

### Change Styling

* Edit `styles.css` to customize:

  * Colors
  * Fonts
  * Layout spacing
  * Navigation styles
  * Responsive behavior
